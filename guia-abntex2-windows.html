Compilar um documento abnTeX2 no Windows

Do zero até o PDF, usando MiKTeX + abnTeX2 e um script de três passadas. É o mesmo fluxo que uso na minha qualificação — só precisa ser montado uma vez por máquina.

01O que você precisa

  • Windows 10/11.
  • MiKTeX — a distribuição LaTeX para Windows (gerencia o pdflatex, o bibtex e os pacotes).
  • Um editor de texto para mexer no .tex. Qualquer um serve (Bloco de Notas, VS Code, TeXstudio). O script compila fora do editor.

Não é necessário pagar nada. Tudo é gratuito.

02Instalar o MiKTeX

  1. Baixe em miktex.org/download e instale com as opções padrão.
  2. Após instalar, abra o MiKTeX Console (busca no menu Iniciar).
  3. Vá em Updates → Update now para atualizar os pacotes base.
Importante — pacotes sob demanda

No MiKTeX Console, vá em Settings → General e deixe “Install missing packages on-the-fly” como Always. Assim, qualquer pacote que o documento peja (o abnTeX2 e suas dependências) é baixado automaticamente na primeira compilação, sem você precisar caçar nada.

03Instalar o abnTeX2

O abnTeX2 é a classe que formata o documento nas normas ABNT (NBR 14724, 6023, 10520). Ele é um pacote LaTeX normal e vive no mesmo repositório do MiKTeX.

Com a opção on-the-fly = Always ativa (passo 2), o abnTeX2 é instalado sozinho na primeira compilação. Se preferir instalar à mão antes:

  1. No MiKTeX Console, vá em Packages.
  2. Busque por abntex2 e clique no + para instalar.
  3. Instale também abntex2cite (vem junto, mas confirme).

04Organizar a pasta

Crie uma pasta para o trabalho e monte esta estrutura. Os nomes dos arquivos importam porque o main.tex os referencia por caminho.

pasta do trabalho/
meu-trabalho/
├── main.tex              ← arquivo principal (a raiz do documento)
├── compilar.ps1          ← o script de compilação
├── ref/
│   └── referencias.bib   ← bibliografia (BibTeX)
├── cap/
│   └── introducao.tex    ← um arquivo .tex por capítulo
└── fig/
    └── (figuras em .pdf ou .png)

Os arquivos .tex dos capítulos e o .bib podem começar vazios — o importante é existirem, senão a compilação reclama de arquivo não encontrado.

05O arquivo principal (main.tex)

Este é um main.tex mínimo e funcional, no mesmo padrão da minha qualificação. Cole no arquivo e ajuste os dados (título, autor, orientador, preâmbulo).

main.tex
% Classe abnTeX2 (ABNT NBR 14724) + citações alfabéticas (autor-data)
\documentclass[
  12pt,
  oneside,          % frente única
  a4paper,
  chapter=TITLE,
  section=TITLE,
  brazil
]{abntex2}

\usepackage[T1]{fontenc}
\usepackage[utf8]{inputenc}
\usepackage{graphicx}
\usepackage[alf]{abntex2cite}   % citações ABNT autor-data

\graphicspath{{fig/}}            % procurar figuras em fig/

\titulo{Título do trabalho}
\autor{Nome do Autor}
\local{Cidade}
\data{2026}
\orientador{Prof. Dr. Fulano de Tal}
\instituicao{Universidade X\par Programa de Pós-Graduação em Y}
\tipotrabalho{Trabalho acadêmico}
\preambulo{Trabalho apresentado ao Programa de Pós-Graduação em Y
  da Universidade X como requisito parcial para...}

\begin{document}

\frenchspacing

% --- pré-textuais ---
\imprimircapa
\imprimirfolhaderosto

\pdfbookmark[0]{\contentsname}{toc}
\tableofcontents*
\cleardoublepage

% --- textuais ---
\textual
\include{cap/introducao}      % um arquivo por capítulo

% --- pós-textuais ---
\postextual
\bibliography{ref/referencias}

\end{document}

E o esqueleto de um capítulo:

cap/introducao.tex
\chapter{Introdução}

Este é o primeiro parágrafo da introdução. O abnTeX2 cuida da
numeração, do espaçamento 1,5 e do recuo de primeira linha.

\section{Contexto}
Texto da seção...

Para citar um autor: \cite{autor2020}.

E o arquivo de bibliografia, com ao menos uma entrada (senão o BibTeX dá erro de nada a processar):

ref/referencias.bib
@book{autor2020,
  author    = {Nome do Autor},
  title     = {Título da Obra},
  year      = {2020},
  publisher = {Editora},
  address   = {Cidade}
}
Atenção — comentários dentro de entradas .bib

Não coloque comentários (%) dentro de uma entrada @book{...}. O BibTeX os lê mal e quebra a entrada inteira. Se precisar anotar algo, ponha o comentário em linha própria, fora das chaves.

06O script de compilação

A compilação de um documento com bibliografia não é um comando só: ela precisa de três passadas do pdflatex intercaladas com uma do bibtex, para resolver citações, sumário e lista de figuras. Em vez de digitar isso a cada vez, use este script.

Salve como compilar.ps1 na raiz da pasta (ao lado do main.tex):

compilar.ps1
# Compila o documento (pdflatex -> bibtex -> pdflatex x2).
# Uso: .\compilar.ps1
$ErrorActionPreference = 'Stop'
Set-Location $PSScriptRoot

pdflatex -interaction=nonstopmode -halt-on-error main.tex
if ($LASTEXITCODE -ne 0) { throw "pdflatex falhou (1a passada) - ver main.log" }

bibtex main
if (-not (Test-Path main.bbl)) { throw "bibtex nao gerou main.bbl - ver main.blg" }

pdflatex -interaction=nonstopmode -halt-on-error main.tex | Out-Null
if ($LASTEXITCODE -ne 0) { throw "pdflatex falhou (2a passada) - ver main.log" }

pdflatex -interaction=nonstopmode -halt-on-error main.tex
if ($LASTEXITCODE -ne 0) { throw "pdflatex falhou (3a passada) - ver main.log" }

Write-Host "`nOK -> $PSScriptRoot\main.pdf"

O -halt-on-error faz o processo parar no primeiro erro (em vez de seguir e gerar um PDF quebrado). O script aborta com mensagem se algo falhar — é mais fácil diagnosticar.

07Compilar

  1. Abra o PowerShell (menu Iniciar → digite “powershell”).
  2. Vá até a pasta do trabalho:
    powershell
    cd C:\Caminho\Para\meu-trabalho
  3. Rode o script:
    powershell
    .\compilar.ps1

Na primeira vez, o MiKTeX baixa o abnTeX2 e as dependências — pode demorar alguns minutos e aparecerão mensagens de “installing package…”. É normal. Ao final, aparece:

saída
OK -> C:\Caminho\Para\meu-trabalho\main.pdf

Abra o main.pdf — ele é regerado a cada compilação.

Atenção — política de execução do PowerShell

Se aparecer o erro “não pode ser carregado porque a execução de scripts foi desabilitada neste sistema”, rode uma vez, como Administrador:

powershell (admin)
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Isso permite rodar scripts locais (o seu) e só exige assinatura para scripts baixados da internet. Depois rode o .\compilar.ps1 de novo.

08Problemas comuns

“Package X not found” / pacote não instalado

Confirme que on-the-fly = Always está ativo (passo 2). Se ainda assim faltar, abra o MiKTeX Console → Packages, busque o nome do pacote e instale. Rode o script de novo.

O script para com “pdflatex falhou (1a passada)”

Há um erro de sintaxe no .tex. Abra o main.log (na mesma pasta) e procure a primeira linha com “! ” — ela diz o erro e a linha aproximada. Corrija e recompile. Erros de LaTeX cascateiam; leia sempre o primeiro, não os seguintes.

“bibtex não gerou main.bbl”

O BibTeX não conseguiu processar as referências. Cheque o main.blg (o log do BibTeX). Causas típicas:

  • O .bib não existe ou o caminho em \bibliography{ref/referencias} está errado (não inclua a extensão .bib no comando).
  • Comentário % dentro de uma entrada @book{...} (ver passo 5).
  • Nenhuma chave \cite{...} no texto e .bib vazio — o BibTeX não tem o que processar.

Acentos aparecem trocados (Ã§, Ã£)

O arquivo .tex foi salvo em outra codificação. Salve como UTF-8 no editor (VS Code: canto inferior direito → “UTF-8”). O \usepackage[utf8]{inputenc} já está no template.

“Overfull \hbox” / “Underfull \hbox” no log

São avisos, não erros — o PDF sai do mesmo jeito. Significam que uma linha ficou um pouco esticada/comprimida. Pode ignorar na maior parte do tempo.

Sobrenome composto sai errado na citação

No .bib, sobrenomes compostos (ex.: “Sousa Silva”) precisam de chaves duplas: author = {{Sousa Silva}, João}. Sem as chaves extras, o abnTeX2 pode pegar só “Silva”.

09Rotina de edição

Depois de montado, o dia a dia é curto:

  • Editou só texto (capítulo, parágrafo): basta uma passada — pdflatex main.tex — e abrir o PDF.
  • Mexeu na bibliografia (adicionou/.removeu entrada, trocou uma citação): rode o .\compilar.ps1 completo, com o bibtex no meio.

Na dúvida, rode o script inteiro. Ele é idempotente — rodar a mais nunca estraga nada.
